# STAGE 프로젝트 계획

졸업논문 「실시간 표정 인식을 이용한 감정 기반 TTS 보컬 합성 시스템 연구」(단국대 뮤직테크놀러지, 2025.11)를 KCI 등재 학술지 논문으로 발전시키는 프로젝트.

## 이름 (2026-10-12 변경)

| 용도 | 이름 |
|---|---|
| 시스템 / 논문 표기 | **STAGE** (Sentence-wise Tone Adaptation Guided by facial Expressions) |
| GitHub 저장소 / 폴더 | `face-emotion-tts` |
| 저장소 설명 (About) | STAGE: Sentence-wise Tone Adaptation Guided by facial Expressions — real-time webcam expression → per-sentence emotion tags → emotional TTS |

- 이전 이름 STAGE는 GitHub에 `facevox` 저장소가 여럿 있어(특히 `valleysonata/facevox`, MediaPipe 표정 인식) 바꿨다. 표정·감정 음성 합성 분야에서 STAGE라는 시스템 이름은 검색되지 않았다(2026-10-12).
- 저장소 이름은 기능 나열형(`face-emotion-tts`), 시스템 이름 STAGE는 README 제목과 About에 쓴다.
- 피해야 할 기존 연구 이름: Face-TTS, FEIM-TTS, DEmoFace, FaceSpeak

## 논문 제목 (안)

- 국문: **STAGE: 엔터테인먼트 콘텐츠 제작을 위한 실시간 표정 인식 기반 감정 음성 합성 시스템**
- 영문: **STAGE: A Real-Time Facial Expression-Driven Emotional Speech Synthesis System for Entertainment Content Creation**
- "보컬 합성"은 노래 합성(SVS)으로 읽히므로 "음성 합성"으로 바꿈 (실제 시스템은 말하기 TTS)

## 투고 대상 학술지

### 1순위 (10월 말 일정): 한국엔터테인먼트산업학회논문지 제20권 제7호 (KCI 등재)

| 단계 | 날짜 |
|---|---|
| 투고예정신청서 마감 | **2026-10-13** → office@koen.or.kr |
| 논문 접수 마감 | **2026-10-23** |
| 발행 예정 | 2026-11-30 |

- 공지: https://koen.or.kr/board/notice/article/285283
- 심사료 8만 원 (긴급 20만 원)은 제출할 때 냄. 게재료는 채택된 뒤에 냄. 연구지원기관을 표기하면 10만 원 추가
- 제출물: 학회 양식 원고 (양식을 지키지 않으면 접수 불가), APA7 참고문헌, 논문투고신청서, 저자점검표, KCI 유사도 검사 결과 파일, 모든 저자의 소속과 직위
- 이 주제가 맞는 근거: 이은혜·김유정(2020)의 보컬 기법 논문이 이 학술지에 실렸음
- 일정을 놓치면 제8호(12-30 발행)를 노림. 신청서 마감은 11월 중순, 원고 마감은 11월 하순으로 추정되므로 공지 확인 필요

## 투고 전략 (2026-10-12 결정)

두 학술지 모두 KCI 등재지라 학술적 무게는 같다. 차이는 주제 적합도, 일정, 비용이다.

| | 한국엔터테인먼트산업학회논문지 (1순위) | 디지털콘텐츠학회논문지 (대안) |
|---|---|---|
| 분과·적합도 | 6분과 인포테인먼트. 사용자 경험·몰입·산업 활용으로 풀어 써야 함. 기술·성능 위주면 배제 위험, 사용자 연구 없음이 약점 | 기술 시스템 논문이 자연스럽게 맞음 |
| 일정 | 신청서 10/13 → 1주 안에 편집위 적합성 답변 → 원고 10/23 → 발행 11/30 | 상시 투고, 결과 5~6주 |
| 비용 | 정회원 5~8만 + 심사료 8만 + 게재료(미확인) | 심사료 없음, 게재료 30만(10쪽) |
| 양식 | HWP만 | 투고 시 확인 |

**순서**
1. 10/13 엔터테인먼트산업학회에 투고예정신청서 제출. 신청서는 투고가 아니므로 이중투고가 아니다.
2. 편집위원회가 주제 적합 판정 → 엔터테인먼트산업학회로 10/23 투고.
3. 부적합 판정 → 같은 원고를 디지털콘텐츠학회논문지 양식으로 바꿔 상시 투고. 그때 비용·양식·KCI 등재 현황을 dcs.or.kr에서 다시 확인.
4. 정식 투고는 한 곳에만 한다.

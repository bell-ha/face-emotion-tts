### 목록 전체의 형식 문제 (KOEN 기준)
1. **번호 매기기(1., 2., …) 삭제.** KOEN은 저자-연도 방식이며 번호를 붙이지 않는다.
2. **정렬**: 현재 무작위 순서 → 국문 가나다순, 그다음 영문 알파벳순.
3. 학술지명과 권은 이탤릭, 학위논문·단행본 제목은 이탤릭.
4. DOI가 있으면 반드시 `https://doi.org/…`로. DBpia·Semantic Scholar·IEEE Xplore 링크는 DOI가 있으면 DOI로 바꾼다.
5. 웹자료 접근일("Retrieved September 10, 2025, from") 삭제 (수시 갱신 페이지만 허용).
6. 학술대회명 약어 금지(이미 대부분 풀어 썼음).

### `references_list.docx`(작업용 목록)에만 있던 문제
최종 PDF 목록에서는 빠졌지만, 원고를 만들 때 이 파일을 다시 쓰지 않도록 기록한다.
- 블로그·홍보 글: 브런치(뷰티펄, 2019), CLOVA Tech Blog(2024), 재능넷(2024) → 학술 근거로 부적합, 쓰지 않음.
- `DBpia. (n.d.). TTS 시스템을 이용한 감정 합성 모델에 관한 연구` → 유은정 논문의 중복 항목(저자를 DBpia로 잘못 씀).
- 「혁신 확산 이론에 기반한…」이 저자 없이 (n.d.)로 두 번 들어 있음.
- Luo et al. 항목 끝에 `arXiv+11ResearchGate+11Dorien Herremans+11` 같은 검색 결과 잔여 문자열이 붙어 있음.

## 5. 인용 외에 함께 고칠 것 (졸업논문에서 발견)

1. **그림 1 캡션 오타**: "Tractron" → "Tacotron".
2. **표 1(FER2013 구성) 비율 오류**: 표의 비율 합이 102.0%다. 샘플 수(합 35,887)로 다시 계산하면 Angry 13.8%, Disgust 1.5%, Fear 14.3%, Happy 25.0%, Sad 16.9%, Surprise 11.2%, Neutral 17.3% (합 100.0%). 원고에서는 실제 분할(Training/PublicTest/PrivateTest) 기준으로 다시 집계한다.
3. 각주 9 "FastSpeech29"은 본문 "FastSpeech2"에 각주 번호 9가 붙은 것. 학술지 원고에서는 각주 대신 인용(Ren et al., 2021)으로.
4. GPT-4o-mini-tts 구조 서술(7쪽)은 근거 없음 → 삭제 (2장 표 참고).
5. "보컬 합성(SVS)" 서술과 실제 시스템(말하기 TTS)이 다르므로, 학술지 원고에서는 "감정 음성 합성"으로 통일하고 SVS 관련 인용(Luo et al., 2020; 송미연, 2019)은 빼거나 배경 한 문장으로 줄인다.

# 감정별 합성 샘플

`app/tts/app.py`의 감정 프리셋(음성 shimmer)으로 합성한 샘플입니다. (2025-08-23)

| 파일 접두어 | 문장 |
|---|---|
| `greeting_*` | 안녕하세요 만나서 반갑습니다 |
| `rabbit_*` | 깊은 숲속 오두막집에서 작은 토끼가 조심스레 문을 열고 밖으로 나왔어요 |

| 접미어 | 감정 | speed |
|---|---|---|
| `happy` | 행복 | 1.22 |
| `sad` | 슬픔 | 0.85 |
| `angry` | 분노 | 1.15 |
| `surprise` | 놀람 | 1.25 |
| `fear` | 두려움 | 0.92 |
| `neutral` | 중립 | 1.0 |

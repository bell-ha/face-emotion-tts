# E3. 감정 음성 렌더링 평가 (속도 단독 vs 명시적 운율 제어)

작성: agent-tts, 2026-10-12. 모든 수치는 이 폴더의 스크립트를 실제로 돌려 얻은 값이다(시드 42).

## 1. 목적

졸업논문 구현은 `gpt-4o-mini-tts`에 `speed`와 문장부호 재작성만 넘겼고, 감정 지시문(`instruction`)은 TTS 호출에 전달되지 않았다(`tts/app.py`의 `tts_one`, `client.audio.speech.create(... speed=speed, input=perf_text)`). 이 실험은 다음 두 가지를 객관 지표로 확인한다.
(1) 속도만 바꾸는 방식이 감정 전달에 부족한가. (2) 학습 없이 기존 TTS에 붙일 수 있는 명시적 운율 제어(SSML prosody 프리셋 + PSOLA 후처리)가 감정 전달을 얼마나 개선하며, 그 대가(화자 정체성, 음질)는 무엇인가.

사람 청취 평가는 하지 않았다. 감정 전달은 자동 음성 감정 인식(SER) 모델 **emotion2vec_plus_large**로 대리 측정했다(한계 참조).

## 3. 프리셋 설계와 튜닝 절차 (검증 타당성)

- 각 감정의 **방향**(높/낮, 빠름/느림, 범위 확대/축소, 음성 품질)은 졸업논문 프리셋 서술(`tts/app.py` `EMOTION_PRESETS["instruction"]`)과 운율 문헌(Murray & Arnott, 1993; Scherer, 2003; Juslin & Laukka, 2003; 음성 품질은 Gobl & Ní Chasaide, 2003)에서 정했다. 둘이 상충하는 분노(논문: 낮은 피치 / 문헌: 높은 피치·넓은 범위)와 두려움(논문: 낮은 피치·느림 / 문헌: 높은 피치·빠름)은 양방향 모두 격자에 넣었다. (서지 실존·정확성 확인은 L1 담당)
- **크기**만 dev 4문장(S03~S06)에서 격자 탐색으로 골랐다. 평가 8문장(S01, S02, S07~S12)은 튜닝에 전혀 쓰지 않았다. 논문 수치는 이 held-out 8문장 결과다.
- 목적함수: dev 정답 수(6감정 제한 argmax) + 0.01 × 평균 로그 마진(log10 P(목표) − 최대 log10 P(타 감정), ±10 절단). emotion2vec 출력이 거의 one-hot이라 정답 수 동점을 마진으로 해소했다.
- 순서: C 격자(감정당 40~50조합) → C 고정 → C 출력 위에서 D 격자(감정당 36~216조합).
- 격자는 1차 탐색(`results/tuning_round1/`) 후 **한 번** 수정했다: 경계값이 선택된 축을 한 단계 확장, 두려움이 0/4라 기식(whispery) 잡음·강한 떨림을 후보에 추가, 중립 D 후처리 탐색 추가. 이 수정도 dev 결과만 보고 했다. 2차에서도 여러 감정이 격자 경계(예: 슬픔 rate −40%, 놀람 pitch +90 Hz)를 골랐다. SER 마진은 조작 강도에 따라 단조 증가하는 경향이 있어, 더 넓히지 않고 여기서 멈췄다(자연성 손실은 6.4절 참조).

### 표 1. 조건 C — edge-tts SSML prosody 프리셋 (고정값)

| 감정 | rate | pitch | volume | 방향 근거 | 탐색 격자(rate / pitch / volume) |
|---|---|---|---|---|---|
| 행복 | +0% | +65 Hz | +0% | 높은 F0, 밝음 (논문·문헌 일치) | {0,+10,+20}% / {+10,+20,+35,+50,+65} Hz / {0,+20}% |
| 슬픔 | −40% | −45 Hz | +0% | 낮은 F0, 느림, 약함 (일치) | {−10,−20,−30,−40}% / {−5,−15,−30,−45,−60} Hz / {0,−30}% |
| 분노 | +30% | −5 Hz | +20% | 큼·빠름 (일치), F0 방향은 상충 → 양방향 탐색 | {0,+10,+20,+30}% / {−20,−5,+10,+25} Hz / {+20,+40}% |
| 놀람 | +30% | +90 Hz | +0% | 높은 F0, 빠른 반응 (일치) | {0,+10,+20,+30}% / {+20,+35,+50,+70,+90} Hz / {0,+20}% |
| 두려움 | +30% | −35 Hz | −30% | 작게 (논문), 속도·F0 상충 → 양방향 탐색 | {−15,0,+15,+30}% / {−35,−20,0,+20,+40} Hz / {0,−30}% |
| 중립 | +0% | +0 Hz | +0% | 기본값(=B) | 탐색 안 함 |

edge-tts의 `pitch`는 SSML prosody의 Hz 단위 오프셋이다(SunHi 중립 평균 F0 ≈ 234 Hz이므로 +65 Hz ≈ +6 반음).

### 표 2. 조건 D — PSOLA 후처리 파라미터 (C 출력에 적용, 고정값)

| 감정 | F0 범위 배율 | F0 이동(st) | 윤곽 성형 | 떨림(Hz, st) | 템포 | 고역 기울기(dB) | 이득(dB) | 기식 잡음 SNR(dB) |
|---|---|---|---|---|---|---|---|---|
| 행복 | 1.0 | 0 | 없음 | 없음 | 1.00 | +3 | +2 | 없음 |
| 슬픔 | 0.4 | −2 | 하강(진폭 0 = 미적용) | 없음 | 1.00 | 0 | −4 | 없음 |
| 분노 | 2.0 | −1 | 없음 | 없음 | 1.10 | +3 | +4 | 없음 |
| 놀람 | 1.4 | +2 | 시작 상승 +6 st | 없음 | 1.00 | 0 | +2 | 없음 |
| 두려움 | 0.6 | 0 | 없음 | 없음(후보 6 Hz/0.6 st, 8 Hz/1.0 st 미선택) | 1.00 | −3 | −4 | 20 |
| 중립 | 0.8 | −1 | 없음 | 없음 | 0.95 | −3 | 0 | 없음 |

파라미터 정의(`scripts/prosody.py`의 `apply_dsp`):
- **F0 범위 배율 k, 이동 s**: 각 피치 점을 반음으로 바꾼 뒤 st' = med + k·(st − med) + s (med = 발화 중앙값). Praat `To Manipulation`(10 ms, 75~600 Hz) → PitchTier 교체 → overlap-add 재합성.
- **윤곽 성형**: `onset_rise` = 유성 구간 정규화 시간 0에서 +A st, 40% 지점까지 선형 감소해 0. `decline` = +A/2 → −A/2 선형 하강.
- **떨림**: F0에 정현파(주파수 Hz, 깊이 st) 가산.
- **템포**: DurationTier 상수(1/템포)로 길이 조작.
- **고역 기울기**: 1 kHz 1차 버터워스 고역 성분을 (10^(dB/20) − 1)배 가감(발성 노력 근사).
- **이득**: 입력 RMS 기준 상대 이득, 피크가 0.98을 넘으면 피크 정규화.
- **기식 잡음**: 1.5~6 kHz 대역 잡음(시드 42)을 음성 진폭 포락선(20 Hz 저역)으로 변조해 지정 SNR로 혼합.
- D 탐색 격자 전체는 `scripts/tune_dev.py`의 `D_GRID`에 있다.

## 4. 지표

- **음향 특징**(parselmouth, Praat 기본 알고리즘): F0는 자기상관(10 ms, 75~600 Hz) 유성 프레임의 평균(Hz)과 표준편차·5~95% 범위(반음, 100 Hz 기준). 강도는 Praat Intensity에서 최대−35 dB 이상 프레임의 파워 평균(dB, 절대 보정 없음). **발화 속도 = 한글 음절 수 / 발화 구간 시간(강도 최대−35 dB 이상 프레임 합, 무음 쉼 제외)**. 고역비 = 1~4 kHz 대 0~1 kHz 대역 에너지 비(dB). 중립 대비 변화량은 같은 조건·같은 문장의 중립 음성을 기준으로 했다.
- **SER**: `emotion2vec_plus_large`(funasr, hub=hf), 발화 단위. 9클래스를 6감정으로 매핑했다(happy→행복, sad→슬픔, angry·disgusted→분노, surprised→놀람, fearful→두려움, neutral→중립, other/unknown→불일치). 주 지표는 9클래스 argmax를 매핑한 정확도(`acc9`)다. 6감정으로 제한한 argmax(`acc6`, disgusted 확률은 분노에 합산)도 같이 냈다. 이번 데이터에서는 두 값이 모두 같았다(other/unknown이 argmax가 된 경우 0건). macro-F1은 6감정 기준.
- **보조 SER**(교차 확인): `superb/wav2vec2-base-superb-er`(IEMOCAP 4클래스, 영어). 행복·슬픔·분노·중립 항목만 4클래스 정확도로 계산(우연 수준 25%).
- **화자 일관성**: SpeechBrain `spkrec-ecapa-voxceleb` ECAPA-TDNN 임베딩의 코사인 유사도. (i) 같은 조건·같은 문장의 중립 음성과 비교, (ii) B 중립(원 SunHi 음성)과 비교. 척도 기준으로 같은 화자의 다른 문장끼리(B 중립 66쌍), 다른 화자끼리(SunHi vs InJoon, 같은 문장 12쌍)의 값을 함께 쟀다.
- **자연성 대리 지표**: TorchAudio `SQUIM_OBJECTIVE`(참조 없는 STOI/PESQ/SI-SDR 추정)와 `SQUIM_SUBJECTIVE`(MOS 추정. 비매칭 참조로 B의 S05 중립을 쓰고, S05 자신에는 S06을 썼다). 두 모델 모두 정상 동작했다. 둘 다 원래 잡음·잔향 열화를 평가하도록 학습된 모델이라 운율 자연성을 직접 재지는 않는다.
- **통계**: 정확도 95% CI는 문장 단위 클러스터 부트스트랩(10,000회)으로 구했다. 조건 간 차이는 같은 문장·감정끼리 짝지은 정확 McNemar 검정과 차이의 클러스터 부트스트랩 CI로 봤다. 우연 수준(1/6) 대비는 단측 이항검정. 감정 간 음향 차이는 Kruskal–Wallis(효과크기 ε²). SQUIM-MOS와 화자 유사도의 D 대 C 비교는 Wilcoxon 부호순위 검정.

### 6.7 요약

1. 속도만 바꾼 기존 구현(A)의 SER 정확도는 8.3%(1/12)로 우연 수준(16.7%) 이하였고, 감정 간 F0·강도 차이도 없었다(KW p > 0.9).
2. 명시적 운율 프리셋(C)은 held-out 정확도를 56.3%로, PSOLA 후처리(D)는 77.1%로 올렸다(D vs C +20.8%p, McNemar p = 0.002; D vs B +60.4%p).
3. 두려움은 C·D 모두 실패했다(0/8, 1/8, 대부분 놀람으로 인식). 놀람은 후처리(시작 상승 윤곽)가 있어야만 인식됐다(0/8 → 7/8).
4. 대가: 큰 F0 이동으로 화자 임베딩 유사도가 다른 화자 수준(≈0.28)까지 떨어졌고, D는 추정 MOS가 C보다 0.3(중앙값) 낮았다.
5. 감정 어휘만 넣은 문장(R1)은 11.1%였다. edge-tts는 텍스트 감정을 운율로 자동 반영하지 않았고, SER도 어휘가 아니라 음향에 반응했다.

## 7. 재사용 모듈 `scripts/prosody.py` (Flask 키 불필요 백엔드용)

```python
import sys; sys.path.insert(0, "experiments/E3_tts/scripts")
from prosody import synthesize, synthesize_bytes, synthesize_array, apply_dsp, norm_emotion, C_PRESETS, D_PRESETS

synthesize_bytes(text: str, emotion: str = "중립", mode: str = "D") -> bytes
    # WAV(24 kHz, mono, PCM16) bytes. Flask: send_file(BytesIO(b), mimetype="audio/wav")
synthesize(text: str, emotion: str = "중립", mode: str = "D", out_path: str | None = None) -> str
    # WAV 파일 저장 후 경로 반환 (out_path 생략 시 임시 파일)
synthesize_array(text, emotion="중립", mode="D") -> np.ndarray   # float64, 24 kHz
apply_dsp(y: np.ndarray, sr: int, params: dict) -> np.ndarray    # 임의 음성에 D 후처리만 적용
norm_emotion(e) -> 'happy'|'sad'|'angry'|'surprise'|'fear'|'neutral'
```

- `emotion`: '행복','슬픔','분노','놀람','두려움','중립', `<행복>` 형태 태그, 영문 키를 모두 받는다. 그 밖의 값은 중립으로 처리.
- `mode`: `"B"`(edge-tts 중립), `"C"`(SSML 프리셋), `"D"`(프리셋 + PSOLA 후처리, 기본값).
- **E3b 추가(하위 호환)**: `mode="DP"`(또는 `"Dp"`)는 화자 보존형 D-psola다. edge-tts 중립 합성 뒤 모든 운율 변화를 PSOLA로 처리한다. 모든 합성 함수에 `intensity=k` 인자가 추가됐다(기본 1.0 = 위 고정 프리셋, 0 = 중립). 보간 규칙과 평가 결과는 `E3b_intensity/README.md`에 있다.
- edge-tts는 온라인 서비스라 네트워크가 필요하다(실패 시 3회 재시도 후 예외). 이미 이벤트 루프가 도는 환경(Flask async, Jupyter)에서는 별도 스레드에서 실행한다.
- 지연(M1 Max, 짧은 문장 1개, 1회 측정): edge-tts 약 0.9초, 후처리 약 0.1초, `synthesize_bytes(mode="D")` 전체 약 1.8초(첫 호출, librosa 로딩 포함). 체계적인 지연 측정은 E4 담당.
- 출력은 항상 WAV다. 문장 병합 등에 mp3가 필요하면 호출 측에서 pydub로 변환한다.
- 의존성: `edge-tts`, `praat-parselmouth`, `numpy`, `scipy`, `soundfile`, `librosa`.

## 10. 한계

1. **사람 청취 평가가 없다.** 감정 전달은 SER 한 모델(emotion2vec_plus_large)로만 대리 측정했다. 프리셋 크기도 같은 모델로 골랐기 때문에, 문장은 held-out이지만 **모델 수준에서는 이 SER에 맞춰진 것**이다. 독립적인 보조 SER(wav2vec2-SUPERB-ER, 영어 IEMOCAP 4클래스)에서의 개선은 작았다(B 25.0 → C 34.4 → D 40.6%, 우연 25%). 따라서 77.1%를 '사람이 느끼는 감정 전달률'로 해석하면 안 된다.
2. emotion2vec 출력은 거의 one-hot(최대 확률 ≈ 1.0)으로 과신한다. SunHi 기본 음성 자체도 dev 문장 일부에서 '행복'으로 분류됐다(음성 설명 "Friendly, Positive").
3. 튜닝은 SER 마진만 최적화했고 자연성·화자 유지 제약은 넣지 않았다. 그래서 슬픔 −40% 속도, 놀람 +90 Hz, 분노 F0 범위 2배처럼 격자 경계의 강한 조작이 선택됐고, 화자 유사도와 추정 MOS가 떨어졌다. 실서비스에서는 강도를 낮추는 쪽이 적절할 수 있다(정확도–자연성 절충).
4. 화자 유사도는 ECAPA 임베딩 기준이다. ECAPA는 F0 이동에 민감하므로 '사람이 다른 화자로 지각한다'는 뜻은 아니다. 다만 ±6 반음 이동은 지각적으로도 음색 변화가 크다.
5. SQUIM은 잡음·잔향 열화용으로 학습된 모델이라 운율 부자연스러움을 직접 재지 않는다.
6. A는 2문장(12개)뿐이고 엔진·화자가 B~D와 다르다. A의 결과는 '속도 단독 제어 + 지시문 미전달'인 졸업논문 구현의 진단으로만 해석해야 하며, gpt-4o-mini-tts에 `instructions`를 넘겼을 때의 성능은 키가 없어 측정하지 못했다.
7. 단일 여성 화자(SunHi), 평가 문장 8개, 감정당 8개로 규모가 작다. 두려움은 이번 방법(F0·속도·강도·떨림·기식 잡음)으로 표현하지 못했다.
8. edge-tts는 외부 온라인 서비스라 서버 측 모델이 바뀌면 결과가 달라질 수 있다(생성일 2026-10-12).

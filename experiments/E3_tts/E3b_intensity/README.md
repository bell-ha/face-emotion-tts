# E3b. 감정 강도(intensity) 제어와 화자 보존형 변형(D-psola)

작성: agent-tts, 2026-10-12. 공통 규칙은 `docs/experiment-plan.md`와 `../README.md`(E3)를 따른다. 모든 수치는 실제로 돌린 결과다(시드 42).

## 1. 목적

E3에서는 SER 정확도가 오를수록 화자 정체성과 음질이 떨어졌다. E3b는 이 절충을 창작자가 조절할 수 있는 **감정 강도 k**로 바꾸고, 화자를 보존하는 변형을 찾는 것이 목적이다.

1. **D-psola(Dp)**: edge-tts는 **중립**으로만 렌더링한다(SSML 피치·속도 이동 없음). 평균 F0, 범위, 윤곽, 템포, 강도 변화는 모두 parselmouth PSOLA로 처리한다. PSOLA는 포먼트를 보존한다.
2. **강도 k ∈ {0, 0.25, 0.5, 0.75, 1.0}**: D와 Dp 양쪽에서 각 프리셋의 중립 대비 편차에 k를 곱한다. k=0은 중립, k=1은 E3의 고정 프리셋이다.
3. 위 10개 (변형, k) 조합을 held-out 8문장에서 평가하고, 권장 운용점은 dev 4문장(S03–S06) 결과만으로 고른다.

## 2. 방법

### 2.1 D-psola 프리셋 도출 (dev만 사용, SER 튜닝 없음)

`scripts/derive_dpsola.py`. dev 문장에서 C 단계(edge-tts SSML)가 B 대비 만든 변화를 측정한 뒤 PSOLA 파라미터로 옮기고 D 값과 합쳤다.
`f0_shift = ΔF0_C + D.f0_shift`, `tempo = (1 + Δrate_C/100) × D.tempo`, `gain_db = ΔInt_C + D.gain_db`. 범위 배율, 윤곽, 떨림, 고역 기울기, 기식 잡음은 D 값을 그대로 썼다.

**표 1. D-psola 프리셋**과 dev에서 측정한 C 단계 변화(B 대비)

| 감정 | dev ΔF0_C (st) | dev Δ속도_C (%) | dev Δ강도_C (dB) | dev Δ고역비_C (dB, 옮기지 않음) | → Dp F0 이동 (st) | Dp 템포 | Dp 이득 (dB) | 범위·윤곽·기울기·기식 잡음 |
|---|---|---|---|---|---|---|---|---|
| 행복 | +6.08 | −0.2 | 0.0 | **+4.89** | +6.08 | 0.998 | +2.00 | D와 같음 |
| 슬픔 | −6.12 | −39.1 | 0.0 | −1.22 | −8.12 | 0.609 | −3.99 | D와 같음 |
| 분노 | −0.59 | +28.3 | +1.55 | −0.36 | −1.59 | 1.412 | +5.55 | D와 같음 |
| 놀람 | +6.92 | +29.0 | −0.11 | **+5.73** | +8.92 | 1.290 | +1.89 | D와 같음 |
| 두려움 | −4.66 | +29.0 | −3.18 | −1.30 | −4.66 | 1.290 | −7.18 | D와 같음(기식 잡음 20 dB) |
| 중립 | 0 | 0 | 0 | 0 | −1.00 | 0.950 | 0.00 | D와 같음 |

edge-tts의 Hz 단위 피치 이동은 고역비를 4.9–5.7 dB 올린다. 피치와 함께 포먼트나 음색도 바뀐다는 뜻으로 해석된다. Dp는 이 스펙트럼 변화를 일부러 옮기지 않았다.

### 2.2 강도 스케일링 (`prosody.scale_c_preset`, `prosody.scale_dsp_params`)

| 파라미터 | 보간 방식 (k) |
|---|---|
| SSML rate %, pitch Hz, volume % (D의 C 단계) | 선형: k × 값 (정수로 반올림) |
| F0 이동 (st), 윤곽 진폭 (st), 떨림 깊이 (st), 고역 기울기 (dB), 이득 (dB) | 선형: k × 값 |
| F0 범위 배율, 템포 | 기하: 값^k |
| 기식 잡음 | 잡음 진폭 k배(SNR + 20·log10(1/k)), k=0이면 없음 |

k=0에서 두 변형은 같은 음성이 된다(B 중립에 항등 PSOLA 재합성).

### 2.3 지표

E3와 같다. emotion2vec_plus_large 정확도(9클래스 매핑)와 macro-F1, wav2vec2-SUPERB-ER 4클래스 정확도(행복·슬픔·분노·중립, 우연 25%), SQUIM 추정 MOS(6감정 전체)를 쟀다.
**화자 유사도**는 감정 음성(중립 제외)과 원 SunHi 음성(E3 `audio/B`, 같은 문장 중립)의 ECAPA 코사인이다. E3 표 7의 '같은 조건 중립 대비'와 기준이 다르다. 여기서는 처리하지 않은 원 화자가 기준이다.
95% CI는 문장 단위 클러스터 부트스트랩(5,000회)으로 구했다. 짝지은 비교에는 정확 McNemar(정확도)와 Wilcoxon(화자 유사도·MOS)을 썼다.

### 2.4 권장 운용점 규칙 (실행 전에 고정, dev만 사용)

k>0 후보 가운데 **dev 화자 유사도 ≥ 0.60 그리고 dev SQUIM-MOS ≥ 4.0**인 것 중 dev 정확도가 최대인 점을 고른다. 동점이면 화자 유사도가 높은 쪽을 고른다. 만족하는 후보가 없으면 화자 기준을 0.50으로 낮춘다.

### 3.4 권장 운용점 (dev 규칙)

- dev 후보 중 규칙(화자 ≥ 0.60, MOS ≥ 4.0)을 만족한 것은 **D@0.25 하나뿐**이었다. dev 기준 정확도 37.5%, 화자 0.683, MOS 4.28.
  - Dp@0.25는 dev MOS 3.97로 탈락했다.
  - Dp@1.0은 화자 기준(0.637)은 넘었지만 MOS 2.99로 탈락했다.
- **held-out 결과(D@0.25)**: 정확도 27.1% (95% CI 20.8–31.3), 우연 대비 단측 이항 p = 0.047. macro-F1 0.22, 화자 유사도 0.694, 추정 MOS 4.33. D@1.0 대비 정확도는 −45.8%p였다(McNemar 0 / 22, p < 10⁻⁶).
- 즉 '화자 유지 + 음질 4.0 이상'을 모두 요구하면 이 시스템이 SER로 확인할 수 있는 감정 전달은 우연 수준을 겨우 넘는다. 이 결과는 정직하게 보고한다.
- 민감도 참고(규칙 결정 뒤에 본 것이며 권장 규칙이 아님): MOS 조건을 빼고 화자 ≥ 0.60만 요구하면 dev 기준으로 Dp@1.0이 선택된다(dev 54.2%). 이때 held-out은 정확도 58.3%, 화자 0.662, 추정 MOS 3.17이다.

### 3.5 재현성 관찰 (edge-tts 실행 간 변동)

D@1.0은 E3와 프리셋이 같은데도 held-out 정확도가 E3 77.1%에서 E3b 72.9%로 달라졌다. 원인은 다시 합성한 edge-tts 음성이 매번 조금씩 다르다는 데 있다. 같은 요청으로 B 중립 12문장을 다시 받아 비교했다. 길이는 같았고 파형 상관은 0.9985–0.9995였지만, 차이 신호가 −25 ~ −30 dB 남았다. 이 작은 차이로 SER 판정 4건이 바뀌었다. S01 놀람과 S07 중립은 정답에서 오답이 됐고, S08·S09 두려움은 오답 종류만 바뀌었다(놀람 → 행복). emotion2vec가 거의 one-hot으로 과신하는 모델이어서 판정이 경계에서 쉽게 뒤집힌다. 따라서 **정확도 ±4%p 정도는 합성 측 측정 잡음**으로 봐야 한다. 논문에서는 E3 수치(77.1%)와 E3b 수치(72.9%)를 함께 쓰고 이 점을 밝혀야 한다.

### 3.6 해석

1. **화자 보존 효과는 크다.** Dp는 모든 k에서 화자 유사도를 크게 높였다(k=1: 0.256 → 0.662, k=0.5: 0.446 → 0.811). E3에서 추정한 대로, 정체성 손실의 주원인은 edge-tts의 SSML 피치 이동이었다.
2. **대신 감정 전달은 줄었다.** Dp@1.0은 58.3%로 D@1.0(72.9%)보다 낮았다(p = 0.065, k=0.75에서는 p = 0.021). 가장 큰 차이는 **행복**이다(D 7/8 → Dp 1/8). 같은 +6 반음이라도 포먼트를 보존한 PSOLA 상향은 SER이 '행복'으로 보지 않았다. D의 행복 인식은 edge-tts 피치 이동에 동반된 스펙트럼(음색) 변화(고역비 +4.9 dB)에 기대고 있었을 가능성이 크다. 그 변화가 곧 화자 임베딩을 무너뜨린 원인이기도 하다. 정확도와 화자 정체성이 같은 음향 단서를 두고 경쟁한다는 뜻이다.
3. **추정 MOS는 Dp가 오히려 낮았다**(모든 k에서 0.3–0.4 낮음). 큰 PSOLA 템포 조작(슬픔 0.61배, 분노 1.41배)과 F0 이동이 재합성 잡음을 키운 것으로 보인다. edge-tts가 신경망 안에서 속도를 바꾸는 쪽이 음질에는 유리하다.
4. **절충 곡선**: 화자 유사도 축에서는 Dp가 D를 지배한다(같은 화자 유사도에서 정확도가 더 높음. 예: 화자 ≈ 0.66–0.69에서 Dp@1.0 58.3% 대 D@0.25 27.1%). MOS 축에서는 D가 Dp를 지배한다. 둘 다 만족하는 구간(화자 ≥ 0.6, MOS ≥ 4.0)에서 얻을 수 있는 SER 정확도는 약 25–27%다.
5. 두려움은 어떤 조합에서도 인식되지 않았다(최대 1/8).

## 5. `prosody.py` 변경 (하위 호환)

```python
synthesize_bytes(text, emotion="중립", mode="D", intensity=1.0) -> bytes
synthesize(text, emotion="중립", mode="D", out_path=None, intensity=1.0) -> str
synthesize_array(text, emotion="중립", mode="D", intensity=1.0) -> np.ndarray
# mode: "B" | "C" | "D" | "DP"/"Dp"(대소문자 무관)   intensity: k (기본 1.0 = 기존 동작, 0 = 중립)
scale_c_preset(cp, k) -> dict      # SSML 프리셋 스케일
scale_dsp_params(p, k) -> dict     # PSOLA 파라미터 스케일
DP_PRESETS                         # 표 1의 값 (= results/dpsola_presets.json)
```

`mode="C"`에 intensity를 주면 SSML 값만 스케일된다. `mode="B"`는 intensity를 무시한다. 기존 호출(인자 생략)의 출력은 바뀌지 않는다.

## 8. 한계

E3의 한계(사람 평가 없음, SER 단일 모델이 대리 지표, SQUIM은 운율 자연성을 직접 재지 않음, 단일 화자, 소규모)가 그대로 적용된다. 덧붙여 다음이 있다.
- Dp 프리셋은 SER로 따로 튜닝하지 않고 C 단계의 측정 변화를 옮겨 만들었다. 따라서 Dp에 불리한 비교일 수 있다(D는 SER 마진으로 직접 튜닝됨).
- 강도 k의 선형/기하 보간은 설계 선택이며, 지각적으로 등간격이라는 보장은 없다.
- 권장점 규칙의 임계값(0.60, 4.0)은 사전에 정했지만 근거는 경험적이다(0.60은 같은 화자·다른 문장 기준 0.80과 다른 화자 기준 0.21 사이). 결과가 임계값에 민감하다(3.4절 민감도 참고).
- edge-tts 실행 간 변동으로 정확도에 ±4%p 정도의 측정 잡음이 있다(3.5절).
